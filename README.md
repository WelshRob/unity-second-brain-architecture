# Unity / Second Brain Architecture

A neutral architecture and review repository for comparing and evolving two independent AI-system workstreams:

- **Unity / CITADEL** — control-plane, orchestration, permissions, routing, approvals and audit.
- **James's Second Brain** — provider-neutral durable knowledge and memory architecture.
- **Reference Architecture** — cross-system design work that may inform either project without making one subordinate to the other.

## Authority model

The original Unity/CITADEL repository remains authoritative for Gareth's implementation.
The original Second Brain repository remains authoritative for James's implementation.
This repository is authoritative only for comparative reviews, architectural analysis, agreed cross-system principles, reference designs and decisions made here.

## Working rule

No change is copied back into either source project automatically. Proposals here remain proposals until explicitly accepted by the owner of the relevant source project.

## Public repository rule

This repository is intentionally public. Only sanitised architectural material may be committed. Credentials, private memory, personal/legal/health information, account details, trading evidence, secrets and unrelated private source material must remain outside this repository.

## Initial baseline

Established 24 August 2026 from the sanitised Unity/CITADEL v2 review bundle supplied for read-only architectural review.
