# ADR-0001 — Neutral Architecture Repository

**Status:** Accepted  
**Date:** 24 August 2026

## Decision

Maintain a separate neutral repository for comparative architecture work involving Unity/CITADEL and James's Second Brain.

## Rationale

Neither source project should become subordinate to the other. Their own repositories remain authoritative for implementation. This repository preserves reviews, cross-system principles and reference architecture without silently modifying either source system.

## Consequences

- Reviews can be preserved independently.
- Proposed shared architecture remains non-binding until explicitly adopted.
- Source-project ownership and history remain clean.
- Cross-system decisions can be traced separately from implementation commits.
